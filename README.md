# Tyter

Редактор киносценариев с бесплатной и PRO веб-версиями. Лендинг — https://tyterapp.github.io, пробный редактор — /free, вход по email/ключу — /pro, страница ошибки — /404. MVP работает целиком на GitHub Pages; отдельный сервер не требуется. Установщики в текущем этапе не меняются.

| Возможность                                            | Бесплатно          | PRO в браузере                      |
| ------------------------------------------------------ | ------------------ | ----------------------------------- |
| Документы / компоненты                                 | 2 / 10 на сценарий | Без ограничений                     |
| История                                                | 14 дней            | Без ограничения срока               |
| Реквизит и отчёт PDF                                   | —                  | Да                                  |
| Аутлайн с карточками, сценами и графиком драматичности | —                  | Да                                  |
| Импорт/экспорт TYT со всеми данными                    | —                  | Да                                  |
| Комментарии, поиск, форматирование, PDF/DOCX/FDX       | Да                 | Да                                  |
| Хранение                                               | Браузер            | Браузер и выбранная локальная папка |

PRO читает https://tyterapp.github.io/codes-for-pro.txt с проверочными хешами и разрешает вход только по совпавшей паре [code][email] из секрета TYTER_PRO_CODES. Пустой или некорректный email не даёт доступа. Успешный вход запоминается в браузере как хеш пары без срока истечения; доступ проверяется при открытии, раз в минуту и при возвращении во вкладку. Интернет нужен для проверки, документы остаются на устройстве.

На сайт публикуются только хеши, без исходных ключей и email. Браузерную проверку можно обойти изменением JavaScript; это ограничение статического MVP.

## Публикация

Полная инструкция с командами Git Bash: [GitHub Pages MVP](docs/GITHUB_PAGES_MVP.md).

Для уже созданного репозитория: [обновление файлов и приложения через Git Bash](docs/GITHUB_PAGES_UPDATE.md).

Используйте репозиторий tyterapp/tyterapp.github.io и Source = GitHub Actions. Workflow **Publish Tyter MVP** читает ваш существующий repository secret **TYTER_PRO_CODES**, собирает лендинг, редакторы и файл с хешами для проверки доступа. После изменения секрета обязательно запустите Actions → Run workflow заново.

В исходном архиве нет реального списка ключей, пользовательских документов, зависимостей и установщиков.

## Разработка и проверки

Node.js 22+, npm ci, npm run dev.

- npm run build — фронтенд.
- npm run site:github — статическая сборка Pages; в Actions читает TYTER_PRO_CODES, локально — исключённый из Git codes-for-pro.txt. Публикует только хеши.
- npm run site:github:preview — проверка готового сайта на http://127.0.0.1:4181/.
- npm run site:github:source — архив исходников для загрузки.
- npm run test:pages — проверки PRO и маршрутов на статической сборке.
- npm test — проверки редактора в браузере.

## Работа

Ctrl+1…7 меняет тип абзаца, Ctrl+Enter принимает подсказку или создаёт компонент, Ctrl+D создаёт компонент из выделения, Ctrl+E создаёт реквизит. Ctrl+клик открывает редактирование. Правый клик показывает действия с текстом и русские орфографические подсказки.

Ctrl+Alt+стрелка вправо/влево переключает текущий абзац на следующий/предыдущий формат по кругу; подсказки в интерфейсе по-прежнему показывают Ctrl+1…7.

Все точные повторения названия компонента автоматически связываются с ним во всём сценарии без учёта регистра, включая ранее написанный текст и новые упоминания. Форматирование и комментарии сохраняются; автоматические связи входят в TYT.

Поиск, статистика, компоненты, реквизит и комментарии находятся в левой вертикальной панели. Ниже — история, скачивание, настройки и помощь. Сайдбары открываются слева от документа. В аутлайне инструменты сценария скрыты; нижняя панель содержит только семь форматов. Для компонентов и реквизита можно загрузить миниатюры JPG, PNG или WebP до 5 МБ одной кнопкой с иконкой «Загрузить картинку». Стандартное поле выбора файла скрыто; после загрузки кнопка называется «Заменить картинку». Миниатюры отображаются в сайдбаре; увеличенный просмотр появляется только при наведении мыши на название в тексте, строку в списке или миниатюру. Картинки сохраняются локально, в истории и в TYT, но не вставляются в текст сценария.

Переключатели RU / ENG и «Сценарий / Аутлайн» находятся справа сверху. Alt+1 открывает сценарий, Alt+2 — аутлайн. Язык интерфейса запоминается на устройстве; переводятся меню, формы, подсказки, справка, лендинг и вход в PRO. Текст сценария, карточек и введённые пользователем названия не переводятся. Клик по пустому месту листа ставит курсор в конец текста. Пустой сценарий показывает подсказку «Начни писать свою историю...», которая не входит в сохранённый документ и экспорт.

Иконка помощи открывает вкладки «Онбординг» и «Горячие клавиши» со всеми сочетаниями редактора. Esc закрывает всплывающие окна, меню, подсказки и сайдбары; в сценарии фокус возвращается к тексту.

В заголовках сцен подсказки компонентов появляются с первой буквы рядом с ИНТ./ЭКС. и временем суток. Совпадающий вариант показывается один раз с иконкой компонента; Ctrl+Enter вставляет его с сохранением связи.

Новый сценарий сразу готов к вводу текста. Позиция курсора сохраняется для каждого документа на этом устройстве и восстанавливается при переключении сценариев и повторном открытии страницы. Добавление сцен из аутлайна и обновления документа сохраняют позицию в текущем абзаце.

Аутлайн содержит акты, карточки, поиск, цветовые метки и комментарии. Карточки можно перетаскивать внутри акта и между актами; место вставки подсвечивается, порядок сохраняется. Новая карточка вставляет сцену; тексты редактируются независимо. Прицел и синий значок у сцены связывают оба режима.

Стрелка слева от названия акта сворачивает и разворачивает его карточки. Состояние сохраняется в локальной библиотеке и TYT. Поиск временно показывает совпадения даже в свёрнутом акте. Точки графика используют цвет карточек; соединяющие линии плавно переходят от цвета одной карточки к цвету другой и обновляются при редактировании.

В редакторе карточки задаётся драматичность от 0 до 10. Кнопка «График драматичности» открывает верхнюю панель над аутлайном со всеми актами в порядке карточек, включая скрытые поиском. График адаптируется к ширине основной области до края правого сайдбара; редактор карточки остаётся справа на всю высоту. Поиск и добавление акта находятся в одной строке. Карточки можно редактировать при открытом графике; он обновляется сразу и выделяет точку выбранной карточки. Нажатие на точку открывает соответствующую карточку, сохраняя график. Кнопка графика скрыта, пока панель открыта, и возвращается после её закрытия. Значения сохраняются в TYT, локальной библиотеке и истории.

TYT переносит весь проект, включая комментарии, аутлайн, компоненты, реквизит, авторство, обложку и историю. PRO использует IndexedDB для локальной библиотеки. Chrome/Edge позволяют подключить папку для автосохранения TYT; в других браузерах скачивайте копии вручную. Обычный экспорт использует Courier, титульный лист добавляется при наличии автора/email/года/постера. PDF/DOCX включают постер; FDX — текстовый титульный лист.

В подключённой папке файлы называются по названию сценария: «Глазами кошки.tyt». При изменении названия файл переименовывается после успешного сохранения. Для одинаковых названий добавляются суффиксы «(2)», «(3)»; запрещённые в Windows символы заменяются подчёркиванием. Старые файлы с внутренним ID вместо названия автоматически переименовываются при следующем автосохранении. Ручные резервные копии и чужие файлы не перезаписываются.

Выбор карточки на графике работает по всей высоте полосы шириной 32–88 px, адаптированной к расстоянию между точками. История разделена на вкладки «Сценарий» и «Аутлайн». Изменения названий, текста, драматичности, комментариев и порядка карточек сохраняются в истории аутлайна; последовательный ввод объединяется в одну версию. Можно посмотреть прежний аутлайн и восстановить его независимо от текста сценария. Обе истории сохраняются в TYT.

В настройках «Масштаб документа» увеличивает весь лист, текст, нумерацию и отступы от 100% до 200%. Ctrl + колесо мыши меняет масштаб шагами по 10%; настройка сохраняется отдельно для каждого сценария и в TYT. Масштаб просмотра не меняет переносы строк, число страниц, хронометраж и геометрию экспорта.

PDF использует геометрию полноразмерного листа редактора при масштабе 100%: ширину 856 px, поля слева 104 px и справа 96 px, те же отступы и интервалы абзацев. Стандартный лист с текстом 12 pt составляет 642 × 792 pt. Семейство шрифта в PDF остаётся Courier независимо от шрифта просмотра.

После заголовка сцены отступ составляет 10 px, если следующий блок — действие; между заголовками и перед другими форматами остаётся 20 px. Это правило сохраняется при экспорте PDF и DOCX. Courier New из приложенного архива доступен в RU и ENG, Courier Prime — только в ENG. При переключении на RU выбранный Courier Prime заменяется стандартным Courier. Выбор шрифта сохраняется в TYT; новые шрифты поставляются локально в WOFF2 с обычным, жирным, курсивным и жирным курсивным начертаниями.

В веб-файлах Courier New исправлена нулевая ширина обычного и неразрывного пробела в курсивных начертаниях исходного архива: слова сохраняют разделение, остальные символы не изменены.

Попапы закрываются по клику на фон, только если нажатие и отпускание мыши происходят вне окна. Растягивание поля описания и перетаскивание из окна наружу сохраняют форму и введённые данные. Скроллбары редактора, сайдбаров, аутлайна, попапов и полей ввода используют общий стиль из `src/scrollbars.css`: тонкий светло-серый ползунок и прозрачный фон.

Компоненты и реквизит из выделенного текста создаются сразу без попапа: Ctrl+D, Ctrl+E, кнопки панели выделения и контекстного меню открывают редактирование в сайдбаре. Повторное создание открывает существующий элемент; для текста с компонентом и реквизитом доступны обе формы. Добавление через список в сайдбаре по-прежнему открывает форму создания. Бесплатный лимит в 10 компонентов сохраняется, реквизит доступен в PRO.

Если сцена карточки удалена, «Вставить снова» вставляет её в последнюю позицию курсора в сценарии, сохраняя текст до и после курсора. Сценарий открывается, плавно прокручивается к вставленному заголовку и ставит в него курсор. Прицел существующей карточки также переводит к её сцене при любом масштабе документа.

Точки графика драматичности можно перетаскивать вверх и вниз. Значение изменяется сразу в карточке и на графике, округляется до целого и ограничивается диапазоном 0–10. Нажатие без перетаскивания только выбирает карточку. Значения сохраняются в локальной библиотеке, TYT и истории аутлайна.
