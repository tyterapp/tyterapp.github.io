# Tyter

Редактор киносценариев с бесплатной и PRO веб-версиями. Лендинг — https://tyterapp.github.io, пробный редактор — /free, вход по email/ключу — /beta, страница ошибки — /404. MVP работает целиком на GitHub Pages; отдельный сервер не требуется. Установщики в текущем этапе не меняются.

| ------------------------------------------------------ | ------------------ | ----------------------------------- |
| Документы / компоненты                                 | 2 / 10 на сценарий | Без ограничений                     |
| История                                                | 14 дней            | Без ограничения срока               |
| Карта дня, задания и идеи продолжения                  | —                  | 3D-коллекция, прогресс и монеты     |
| Реквизит и отчёт PDF                                   | —                  | Да                                  |
| Аутлайн с карточками, сценами и графиком драматичности | —                  | Да                                  |
| Импорт/экспорт TYT со всеми данными                    | —                  | Да                                  |
| Комментарии, поиск, форматирование, PDF/DOCX/FDX       | Да                 | Да                                  |
| Хранение                                               | Браузер            | Браузер и выбранная локальная папка |

PRO читает https://tyterapp.github.io/codes-for-pro.txt с проверочными хешами и разрешает вход только по совпавшей паре [code][email] из секрета TYTER_PRO_CODES. Пустой или некорректный email не даёт доступа. Успешный вход запоминается в браузере как хеш пары без срока истечения; доступ проверяется при открытии, раз в минуту и при возвращении во вкладку. Интернет нужен для проверки, документы остаются на устройстве.

На сайт публикуются только хеши, без исходных ключей и email. Браузерную проверку можно обойти изменением JavaScript; это ограничение статического MVP.

## Публикация

Полная инструкция с командами Git Bash: [GitHub Pages MVP](docs/GITHUB_PAGES_MVP.md).

Для уже созданного репозитория: [обновление файлов и приложения через Git Bash](docs/GITHUB_PAGES_UPDATE.md).

Используйте репозиторий tyterapp/tyterapp.github.io и Source = GitHub Actions. Workflow **Publish Tyter MVP** читает ваш существующий repository secret **TYTER_PRO_CODES**, собирает лендинг, редакторы и файл с хешами для проверки доступа. После изменения секрета обязательно запустите Actions → Run workflow заново.

В исходном архиве нет реального списка ключей, пользовательских документов, зависимостей и установщиков.

## Разработка и проверки

Node.js 22+, npm ci, npm run dev.

- npm run build — фронтенд.
- npm run site:github — статическая сборка Pages; в Actions читает TYTER_PRO_CODES, локально — исключённый из Git codes-for-pro.txt. Публикует только хеши.
- npm run site:github:preview — проверка готового сайта на http://127.0.0.1:4181/.
- npm run site:github:source — архив исходников для загрузки.
- npm run test:pages — проверки PRO и маршрутов на статической сборке.
- npm test — проверки редактора в браузере.

## Работа

На экранах шириной 320–831 px редактор переключается в мобильную раскладку: лист помещается по ширине, форматирование остаётся снизу над экранной клавиатурой, компоненты и инструменты открываются через шторки. С 832 px сохраняется настольная раскладка. Мобильная сессия хранит полные проекты в общем локальном складе браузера; подготовлена граница для будущего сетевого хранения. Подробнее: [мобильный редактор](docs/EDITOR_TOOLS.md#мобильный-редактор).

Ctrl+1…7 меняет тип абзаца, Ctrl+Enter принимает подсказку или создаёт компонент, Ctrl+D создаёт компонент из выделения, Ctrl+E создаёт реквизит. Ctrl+Q открывает комментарий к выделенному тексту; сочетание показано в подсказке кнопки над выделением. Ctrl+O открывает FDX, DOCX и PDF, а в PRO также TYT. Ctrl+клик открывает редактирование. Правый клик показывает действия с текстом и орфографические подсказки для RU или ENG.

В настройках документа «Подсветка орфографии» по умолчанию выключена. Выбор сохраняется в документе и в TYT. При включении браузер проверяет русский для RU и английский для ENG; для подчёркивания используется установленный словарь браузера. Подсказки по правому клику работают локально для обоих языков даже при выключенной подсветке. Английский словарь Hunspell и его лицензия находятся в `public/dictionary`.

В веб-версии PRO кнопка выхода закреплена внизу левой панели под знаком вопроса и остаётся видимой при прокрутке инструментов в невысоком окне. Она сохраняет последние изменения, удаляет сессию входа и возвращает к форме email и ключа. Локальные документы остаются на устройстве. Выход также закрывает доступ в других открытых вкладках PRO.

Ctrl+Alt+стрелка вправо/влево переключает текущий абзац на следующий/предыдущий формат по кругу; подсказки в интерфейсе по-прежнему показывают Ctrl+1…7.

В подсказках сцен текст начинается в 10 px от края окна, на одной линии с нижней подсказкой горячих клавиш. В RU предлагаются ИНТ./ЭКС. и ДЕНЬ/НОЧЬ; в ENG — INT./EXT. и DAY/NIGHT независимо от языка уже написанного заголовка. Подсказки понимают начальные буквы обоих языков, а вставляют вариант выбранного языка интерфейса. Названия компонентов не переводятся.

Все точные повторения названия компонента автоматически связываются с ним во всём сценарии без учёта регистра, включая ранее написанный текст и новые упоминания. Форматирование и комментарии сохраняются; автоматические связи входят в TYT.

В PRO реквизит можно группировать по собственным папкам, сворачивать папки и выбирать папку при создании или редактировании. При удалении папки её реквизит перемещается в «Без папки». Папки и их состояние входят в историю и в файлы TYT. Описание компонента, если оно заполнено, показывается при наведении мышью в списке и сценарии, вместе с миниатюрой или без неё; превью ограничено четырьмя строками.

При выборе локальной папки библиотека заменяется сценариями TYT из этой папки. Документы из прежней папки не копируются в новую. Если папка пустая, редактор предлагает создать новый сценарий. При повторном открытии PRO сохраняется выбранная библиотека; старые вкладки не могут записать свои документы в другую папку. Исходные файлы в прежней папке сохраняются. При первом подключении папки прежняя библиотека браузера также остаётся в резервной записи IndexedDB.

Картинку JPG/JPEG, PNG или WebP до 10 МБ можно вставить из буфера обмена через Ctrl+V, пункт «Вставить» в контекстном меню или перетащить в область сценария. При перетаскивании показывается overlay, при вставке — состояние загрузки. После обработки создаётся компонент с миниатюрой и сразу открывается его редактирование в сайдбаре. Названия выбираются без повторов: «Без названия», «Без названия 2» и далее для RU, «Untitled», «Untitled 2» и далее для ENG. Несколько картинок можно вставить одновременно; каждая создаёт свой компонент. Весь набор проверяется до создания компонентов, размер ограничен для каждой картинки отдельно. Esc отменяет загрузку. Обычная вставка текста не меняется, изображения не добавляются в сам текст сценария. Созданные компоненты и миниатюры сохраняются локально и в TYT; бесплатный лимит в 10 компонентов продолжает действовать.

В списке автоподсказок текст вариантов и нижняя подсказка горячих клавиш имеют одинаковый левый отступ. Значок компонента расположен справа от его названия.

Поиск, статистика, компоненты, реквизит и комментарии находятся в левой вертикальной панели. Ниже — история, скачивание, настройки и помощь. Сайдбары открываются слева от документа. В аутлайне инструменты сценария скрыты; нижняя панель содержит только семь форматов. Для компонентов и реквизита можно загрузить миниатюры JPG, PNG или WebP до 5 МБ одной кнопкой с иконкой «Загрузить картинку». Стандартное поле выбора файла скрыто; после загрузки кнопка называется «Заменить картинку». Загруженная картинка сразу показывается в форме создания и редактирования, включая попап. При нажатии на плюс в сайдбаре поле названия сразу получает фокус. Миниатюры отображаются в сайдбаре; увеличенный просмотр появляется только при наведении мыши на название в тексте, строку в списке или миниатюру. Высота превью соответствует пропорциям изображения с ограничением 320 px и доступной высотой экрана; положение обновляется после загрузки картинки. Картинки сохраняются локально, в истории и в TYT, но не вставляются в текст сценария.

В поиске по документу фильтр «Формат текста» ограничивает совпадения заголовками сцен, действиями, персонажами, репликами, ремарками, переходами или обычным текстом. По умолчанию поиск работает по всем форматам. Список результатов, счётчик, подсветка и переходы используют один фильтр; при его смене выбирается первое подходящее совпадение. Названия форматов переводятся вместе с интерфейсом.

Переключатели RU / ENG и «Сценарий / Аутлайн» находятся справа сверху. Alt+1 открывает сценарий, Alt+2 — аутлайн. Язык интерфейса запоминается на устройстве; переводятся меню, формы, подсказки, справка, лендинг и вход в PRO. Текст сценария, карточек и введённые пользователем названия не переводятся. Клик между абзацами или на полях рядом с текстом ставит курсор в ближайшее место текста без перехода к концу документа. Клик по свободной области ниже последней строки ставит курсор в конец текста. Пустой сценарий показывает подсказку «Начни писать свою историю...», которая не входит в сохранённый документ и экспорт.

Иконка помощи открывает вкладки «Онбординг» и «Горячие клавиши» со всеми сочетаниями редактора. Esc закрывает всплывающие окна, меню, подсказки и сайдбары; в сценарии фокус возвращается к тексту.

В заголовках сцен подсказки компонентов появляются с первой буквы рядом с ИНТ./ЭКС. и временем суток. Совпадающий вариант показывается один раз с иконкой компонента; Ctrl+Enter вставляет его с сохранением связи.

Новый сценарий сразу готов к вводу текста. Позиция курсора сохраняется для каждого документа на этом устройстве и восстанавливается при переключении сценариев и повторном открытии страницы. Добавление сцен из аутлайна и обновления документа сохраняют позицию в текущем абзаце.

Аутлайн содержит акты, карточки, поиск, цветовые метки и комментарии. Карточки можно перетаскивать внутри акта и между актами; место вставки подсвечивается, порядок сохраняется. Новая карточка добавляет одну пустую строку заголовка сцены без заготовки текста. Название и текст карточки остаются независимыми от сценария. Поле названия в сайдбаре многострочное и растягивается по высоте; у пустых карточек нет текстовой подсказки. Прицел и синий значок у сцены связывают оба режима.

Стрелка слева от названия акта сворачивает и разворачивает его карточки. Состояние сохраняется в локальной библиотеке и TYT. Поиск временно показывает совпадения даже в свёрнутом акте. Точки графика используют цвет карточек; соединяющие линии плавно переходят от цвета одной карточки к цвету другой и обновляются при редактировании.

В редакторе карточки задаётся драматичность от 0 до 10. Кнопка «График драматичности» открывает верхнюю панель над аутлайном со всеми актами в порядке карточек, включая скрытые поиском. График адаптируется к ширине основной области до края правого сайдбара; редактор карточки остаётся справа на всю высоту. Поиск и добавление акта находятся в одной строке. Карточки можно редактировать при открытом графике; он обновляется сразу и выделяет точку выбранной карточки. Нажатие на точку открывает соответствующую карточку, сохраняя график. Кнопка графика скрыта, пока панель открыта, и возвращается после её закрытия. Значения сохраняются в TYT, локальной библиотеке и истории.

TYT переносит весь проект, включая комментарии, аутлайн, компоненты, реквизит, авторство, обложку и историю. PRO использует IndexedDB для локальной библиотеки. Chrome/Edge позволяют подключить папку для автосохранения TYT; в других браузерах скачивайте копии вручную. Обычный экспорт использует Courier, титульный лист добавляется при наличии автора/email/года/постера. PDF/DOCX включают постер; FDX — текстовый титульный лист.

В подключённой папке файлы называются по названию сценария: «Глазами кошки.tyt». При изменении названия файл переименовывается после успешного сохранения. Для одинаковых названий добавляются суффиксы «(2)», «(3)»; запрещённые в Windows символы заменяются подчёркиванием. Старые файлы с внутренним ID вместо названия автоматически переименовываются при следующем автосохранении. Ручные резервные копии и чужие файлы не перезаписываются.

Выбор карточки на графике работает по всей высоте полосы шириной 32–88 px, адаптированной к расстоянию между точками. История разделена на вкладки «Сценарий» и «Аутлайн». Изменения названий, текста, драматичности, комментариев и порядка карточек сохраняются в истории аутлайна; последовательный ввод объединяется в одну версию. Можно посмотреть прежний аутлайн и восстановить его независимо от текста сценария. Обе истории сохраняются в TYT.

В настройках «Масштаб документа» увеличивает весь лист, текст, нумерацию и отступы от 100% до 200%. Ctrl + колесо мыши меняет масштаб шагами по 10%; настройка сохраняется отдельно для каждого сценария и в TYT. Масштаб просмотра не меняет переносы строк, число страниц, хронометраж и геометрию экспорта.

PDF использует геометрию полноразмерного листа редактора при масштабе 100%: ширину 936 px, поля слева 184 px и справа 96 px, те же отступы и интервалы абзацев. Ширина текстовой области остаётся 656 px. Стандартный лист с текстом 12 pt составляет 702 × 792 pt. Семейство шрифта в PDF остаётся Courier независимо от шрифта просмотра.

В настройках доступны светлая/тёмная тема и звук печатной машинки, по умолчанию выключенный. Эти предпочтения сохраняются на устройстве. Кнопка в правом нижнем углу листа включает режим без интерфейса с небольшой памяткой форматов; повторное нажатие или Esc возвращает панели.

Звук использует 48 записанных MP3 с постоянными назначениями клавиш, включая экранную клавиатуру. У доктора одновременно не больше 12 небольших SVG-мух: возле иконки и поверх интерфейса. Переключатель «Показывать мух» в докторе отключает обе группы и сохраняет выбор на устройстве. Полёты не мешают кликам, приостанавливаются в скрытой вкладке и учитывают уменьшение анимаций. Тёмные поля и горячие клавиши используют согласованные цвета интерфейса.

За первый вход в день начисляется одна монета; каждый пятый день непрерывной серии даёт дополнительный бонус 10 монет. Стрик и общий кошелёк сохраняются на устройстве и синхронизируются между вкладками. Кнопка стрика рядом с таймером показывает серию и рекорд на 10 секунд. Первый пункт списка версий — Note: отдельный редактор заметок Inter 18 px без форматирования текста, с поиском, комментариями, компонентами, историей и сохранением в TYT. Быстро открыть заметки определённой цветной версии можно также кнопкой рядом с её названием.

Выпадающий список A–F после номера сцены переключает независимые версии всей сцены без подсветки строки. Новый вариант копирует текст A; изменения в B–F не переходят в другие, в том числе ещё не открывавшиеся, варианты. Иконка аутлайна остаётся рядом, ссылка на карточку сохраняется при переключении. Поиск показывает текущий вариант и доступные буквы; ищет в активных версиях. TYT и история сохраняют все варианты; PDF/DOCX/FDX экспортируют активные.

«Доктор сценария» на левой панели проверяет заголовки, время суток, пустые сцены, полные дубликаты сцен, соседние одинаковые абзацы действия и нарушения последовательности персонаж/реплика. Нажатие на замечание переводит к строке. Проверки работают локально и обновляются во время ввода.

В сайдбаре компонентов можно экспортировать библиотеку `.tytl`, импортировать библиотеку или извлечь компоненты из TYT. Загруженные библиотеки сохраняются на устройстве. Файлы TYTL из подключённой папки предлагаются для внедрения в сценарий. Встроенные компоненты отмечены иконкой связи; повторный импорт той же библиотеки обновляет выбранные компоненты, сохраняя их идентификаторы. Совпадения с названиями собственных компонентов пропускаются. В бесплатной версии действует лимит 10 компонентов.

При наведении на имя персонажа появляется кнопка просмотра его реплик. Этот режим показывает только реплики и ремарки выбранного персонажа с заголовками сцен. Можно перейти к конкретной реплике, вернуться кнопкой или нажать Esc. Подробнее: [новые инструменты редактора](docs/EDITOR_TOOLS.md).

Если в настройках заполнен автор, email, год или постер, PDF начинается с отдельной титульной страницы: название сценария и заполненные сведения, обложка при наличии. Все поля не обязательно заполнять. Экспорт использует последние значения настроек; титульная страница не нумеруется, первая страница сценария получает номер 1.

После заголовка сцены отступ составляет 10 px, если следующий блок — действие; между последовательными блоками действия также 10 px. Между заголовками и перед другими форматами остаётся 20 px. Это правило сохраняется при экспорте PDF и DOCX. Courier New из приложенного архива доступен в RU и ENG, Courier Prime — только в ENG. При переключении на RU выбранный Courier Prime заменяется стандартным Courier. Выбор шрифта сохраняется в TYT; новые шрифты поставляются локально в WOFF2 с обычным, жирным, курсивным и жирным курсивным начертаниями.

В веб-файлах Courier New исправлена нулевая ширина обычного и неразрывного пробела в курсивных начертаниях исходного архива: слова сохраняют разделение, остальные символы не изменены.

Попапы закрываются по клику на фон, только если нажатие и отпускание мыши происходят вне окна. Растягивание поля описания и перетаскивание из окна наружу сохраняют форму и введённые данные. Скроллбары редактора, сайдбаров, аутлайна, попапов и полей ввода используют общий стиль из `src/scrollbars.css`: тонкий светло-серый ползунок и прозрачный фон.

Компоненты и реквизит из выделенного текста создаются сразу без попапа: Ctrl+D, Ctrl+E, кнопки панели выделения и контекстного меню открывают редактирование в сайдбаре. Повторное создание открывает существующий элемент; для текста с компонентом и реквизитом доступны обе формы. Добавление через список в сайдбаре по-прежнему открывает форму создания. Бесплатный лимит в 10 компонентов сохраняется, реквизит доступен в PRO.

Если сцена карточки удалена, «Вставить снова» вставляет её в последнюю позицию курсора в сценарии, сохраняя текст до и после курсора. Прицел существующей карточки также переводит к её сцене. Сценарий открывается и плавно прокручивается к строке заголовка за 260 мс. Курсор располагается выше середины видимой области, с учётом масштаба, разрывов страниц, горизонтальной прокрутки и нижней панели форматирования. Даже последнюю сцену можно расположить в этой области за счёт дополнительного пространства прокрутки под листом. После перехода заголовок подсвечивается на одну секунду с плавным появлением и исчезновением. Подсветка не сохраняется в TYT, истории или экспорте. Если в системе отключены анимации, переход выполняется сразу, а секундная подсветка остаётся статичной.

Точки графика драматичности можно перетаскивать вверх и вниз. Значение изменяется сразу в карточке и на графике, округляется до целого и ограничивается диапазоном 0–10. Нажатие без перетаскивания только выбирает карточку. Значения сохраняются в локальной библиотеке, TYT и истории аутлайна.
