# Телеграммы и обложки

На GitHub Pages работают переносимые ссылки `/telegram/#telegram=…`: текст и
название сценария находятся в ссылке, обычный посетитель видит только текст
телеграммы и управление воспроизведением. Старые ссылки поддерживаются.
Обложка 1200×630 с логотипом и QR генерируется локально, её можно скачать и
отправить вместе со ссылкой. Длинная переносимая ссылка может превышать ёмкость
QR; тогда QR не рисуется, интерфейс объясняет ограничение.

GitHub Pages отдаёт один статический HTML для всех пользовательских фрагментов.
Поэтому персональная Open Graph обложка ссылки требует публичного сервиса.
Изменение метатегов JavaScript на странице не исправляет превью Telegram.

## Подключение сервиса

Сервис включён в `server/site-server.mjs`. Он хранит только явно опубликованные
текст телеграммы, язык и название сценария. Полный документ, история, комментарии
и компоненты не отправляются. Установка: `npm ci`, `npm run site:build`.
Запуск: `npm run site:serve` с переменными:

- `HOST=0.0.0.0`, `PORT=4173` — адрес прослушивания;
- `TYTER_PUBLIC_ORIGIN=https://share.example.com` — настоящий внешний HTTPS адрес
  за обратным прокси;
- `VITE_TELEGRAM_SERVICE_URL=https://share.example.com` — адрес для сборки
  редактора (нужно пересобрать и заново опубликовать GitHub Pages).

Без `VITE_TELEGRAM_SERVICE_URL` редактор не делает запросы на публикацию и
продолжает создавать переносимые ссылки. При недоступности сервиса они также
остаются рабочим запасным вариантом.

`POST /api/telegrams` принимает `{version:1,language,text,title}` и возвращает
`url` и `coverURL`. Ссылки неизменяемые, идентификатор зависит от содержимого.
`GET /telegram/?id=…` отдаёт сразу HTML с персональными метатегами, а
`GET /api/telegrams/….png` — PNG с текстом, логотипом и QR короткой ссылки.
`GET /api/telegrams/…` возвращает опубликованные данные.

Папка `.shared-telegrams/` находится вне публичной папки сайта, исключена из Git
и архивов исходников. Сохраните её на постоянном диске и включите в резервное
копирование при размещении сервиса. Ссылки публичные: отправитель сознательно
публикует их содержимое. CORS разрешает сам сервис и `https://tyterapp.github.io`;
размер запроса ограничен 100 КБ, публикация — 20 запросами в минуту с одного IP.
