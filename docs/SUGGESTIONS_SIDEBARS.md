# Подсказки при открытых сайдбарах

| Было                                                                                                                    | Стало                                                                                                                                    |
| ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Подсказки сцен и компонентов использовали блокировку панели форматирования; доктор, поиск и правая карточка скрывали их | У подсказок собственный флаг блокировки. Обычные десктопные сайдбары и полноэкранный режим позволяют ввод с подсказками                  |
| Один флаг объединял сайдбары и модальные окна                                                                           | Модальные окна, меню и мобильные шторки блокируют подсказки. Фокус в поле сайдбара также скрывает их; возврат в документ восстанавливает |

Сохранены проверка фокуса, обработка IME, принятие через Ctrl+Enter, скрытие по Escape и стабильное обновление попапа без мигания. Старые вызовы редактора сохраняют прежние ограничения, пока явно не передадут отдельный флаг.
