# Этапы производства, съёмки и награды

| Было                                                    | Стало                                                                                                                                                                                               |
| ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Цвета карточек без подписи                              | Pre production, Production и Post production; общий цвет карточки, значка в документе, истории и графика. Старые данные сохраняются                                                                 |
| Только параметры кадра                                  | Дополнительно дата съёмок и локация с названием и координатами. Выбор на карте или ручной ввод. Данные изолированы по сцене и варианту, сохраняются в файле и входят в PDF-отчёт                    |
| Разные размеры значка и миниатюры                       | Общая кнопка 48×48 px. Для соседних пустых сцен оставлен зазор, без изменения отступов печати                                                                                                       |
| Доктор доступен сразу                                   | По умолчанию скрыт. Баланс → «Магазин»: покупка за 20 монет один раз, с сохранением доступа |
| Монеты только от таймера и стрика                       | Дополнительно 10 монет за каждые 100 новых символов, включая вставку и замену. Unicode-символы считаются целиком, остаток переносится между сессиями. IME учитывается только после завершения ввода |
| Загрузка и служебные изменения могли выглядеть как ввод | Загрузка, переключение варианта, undo/redo, форматирование, перенос текста, готовые заголовки и массовая замена компонентов не дают монеты                                                          |
| Не было журнала удалённых копий                         | Подтверждённые удаления за текущий день показаны внизу истории текущего документа: количество, названия и время. Отмена не записывается                                                             |
| Не было ачивки за удаление копий                        | При удалении последней созданной копии документа — «Мусорщик» и 10 монет, один раз для кошелька пользователя. White защищён                                                                         |

Таймеры и стрики сохраняют прежние правила. Кошелёк общий для документов и вкладок браузера; покупки и награды сериализуются существующим замком. Подтверждение удаления сохраняет отдельную квитанцию до ожидания замка: после закрытия вкладки незавершённая запись восстанавливается при следующем запуске, без повторного начисления.

Карта загружается только при раскрытии свойства. OpenStreetMap указан на карте; при недоступности сети координаты можно задать вручную. Изображение пользователя и выбранное кадрирование сохраняются.
