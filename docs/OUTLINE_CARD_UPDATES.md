# Карточки аутлайна и навигация

Последующие упрощения:

Визуализация мух по умолчанию выключена, в том числе при найденных ошибках. Тумблер позволяет включить её; явный выбор сохраняется на устройстве. Диагностика ошибок работает независимо от визуализации.

| Было                                                  | Стало                                                                                                             |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Значок, пояснение и подпись состояния в настройке мух | Только «Визуализация мух» и тумблер. Состояние по-прежнему доступно программе чтения с экрана через переключатель |
| Значок карточки рядом с заголовком её сайдбара        | Только заголовок; захват ширины, прицел и закрытие сохраняются                                                    |
| Между соседними абзацами формата «Заметки» — 20 px    | 10 px, как между соседними абзацами действия. Общая модель расположения также учитывает этот отступ               |
| Между абзацами сохранённого отдельного Note — 12 px   | 10 px; пункт Note остаётся скрыт                                                                                  |

| Было                                                        | Стало                                                                                                                                                |
| ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Нажатие на значок карточки в сценарии переводило в аутлайн  | Открывает редактор выбранной карточки справа, сохраняя сценарий на экране. Прицел в заголовке переводит к карточке в аутлайне и раскрывает её акт    |
| Фиксированная ширина редактора карточки                     | Ширина от 340 до 480 px. Потяните за захват в заголовке; стрелки меняют ширину на 20 px, Home/End выбирают пределы. Ширина сохраняется на устройстве |
| Общие значки копирования и списка                           | Значки из приложенных `card.svg` и `outline.svg` с `currentColor`, округлыми линиями и толщиной остальных значков интерфейса                         |
| Редактор карточки доступен только в аутлайне                | Один общий редактор для обоих режимов. На мобильном экране карточка из сценария открывается в шторке; слайдер сохраняет оформление настроек          |
| В репликах отображались только номер и название сцены       | Рядом также отображается буква варианта A–F                                                                                                          |
| Мухи кружились внутри значка доктора и летали по интерфейсу | В значке мух нет. Поверх интерфейса они ползают короткими случайными шагами с поворотами и паузами; одновременно не больше 12                        |
| Пункты заданий и Note были доступны в интерфейсе            | Временно скрыты. Сохранённые заметки, задания, монеты и стрики остаются в хранилище                                                                  |

Новые значки наследуют существующие цвета обычного состояния, наведения и тёмной темы; дополнительных цветов для них нет. Мухи используют тёмно-серый SVG размером 9 px, не перехватывают клики, останавливаются в скрытой вкладке и при уменьшении анимаций. Тумблер доктора по-прежнему отключает их полностью.

Проверки: две темы, растягивание и сохранение ширины, независимое редактирование карточки, переход к карточке в свёрнутом акте, новые значки, сохранение скрытых заметок, пометки F/B у диалогов, движение и отключение мух, мобильная шторка на 320 px. Проверки интерфейса скрытых заданий и заметок временно отключены с пояснением; проверки их данных остаются активными.
