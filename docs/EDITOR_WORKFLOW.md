# Быстрое сохранение и первый вход

В Pro `Ctrl+Shift+S` (на Mac также `⌘+Shift+S`) сохраняет отдельную копию текущего проекта в формате TYT. Системный диалог позволяет выбрать папку; в нём заранее стоит имя импортированного или ранее сохранённого файла, без даты и суффикса «копия». При переименовании сценария предлагается новое название. Копия включает все версии, компоненты, комментарии, аутлайн и историю; открытый проект и подключённая папка не переключаются. `Ctrl+S` сохраняет изменения как прежде. Прежнее зачёркивание по `Ctrl+Shift+S` убрано.

В Chrome и Edge используется `showSaveFilePicker`, вызываемый непосредственно по нажатию клавиш до ожидания экспорта. В настольной версии используется диалог Electron. В браузерах без File System Access файл скачивается через обычный механизм браузера, который определяет показ диалога сохранения. Отмена не запускает скачивание; ошибка записи прерывает поток и показывает сообщение. Повторные события при удержании сочетания не открывают новые окна.

В шапке переключатель «Сценарий / Аутлайн» расположен перед языком. Подсказки имеют ширину 264 px вместо 296 px (на узком экране ограничены шириной окна); подписи горячих клавиш удалены, сами сочетания продолжают работать. Переключатель миниатюр перенесён в настройки документа → «Редактор»; сохранённое значение настройки осталось прежним.

Текст с шестью советами по работе с клавиатурой появляется после закрытия обучения при первом запуске с исходным пустым документом. Для русского и английского интерфейса предусмотрены свои тексты. Это отдельный элемент интерфейса над редактором: он не добавляется в содержимое, историю, буфер сценария, экспорт и печать. При вводе, переключении или создании документа блок исчезает; отмена ввода его не возвращает. Повторный вход показывает обычную первую строку ИНТ/ЭКС (INT/EXT) и существующую подсказку начала истории. Факт показа хранится в `tyter.editor-intro.v1`; установленный ранее `tyter.onboarding.v1` исключает показ советов при обновлении существующей установки.
