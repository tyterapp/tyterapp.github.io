# Обучение и действия с текстом

Исполнение в текущем рабочем каталоге; отдельного Git-репозитория здесь нет. Используются Superpowers writing-plans, systematic-debugging и UI Skills baseline-ui. Прямой запрос пользователя задаёт дизайн и объём работ.

Цель: вкладки «Привет! / Горячие клавиши» сверху листа обучения рядом с возвратом; анимация текста только у приветственного заголовка; удаление Props и Ctrl+E из действий с выделением; корректное отключение подсветки в обеих темах; название «HTML презентация» в экспорте.

Архитектура: выделить переиспользуемый список горячих клавиш из существующей справки, собрать отдельный компонент страницы обучения из существующих элементов Tyter. Проверять цвета на реальном DOM редактора и исправить источник каскада, сохранив данные компонентов. React DOM, CSS, Playwright/Edge; новые зависимости не нужны.

Решения: Props убран из действий с выделением и контекстных меню, а существующие записи документа сохраняются. Ошибка цвета воспроизведена для компонента внутри текстовой ссылки: при скрытии подсказок цвет наследовался от внешнего `a.script-text-link`. Исправлен именно этот каскад, включая фон ссылки. Обычные компоненты в обеих темах уже проходили проверку до исправления.

Проверки до изменения приложения: отсутствующие вкладки и Props дали ожидаемые ошибки; отдельный тест вложенной ссылки воспроизвёл цвет `oklch(0.78 0.082 300)` вместо окружающего `rgb(226, 220, 232)`. После исправления шесть новых проверок прошли. В расширенном прогоне прошли 24 из 26 проверок; две старые проверки реквизита адаптированы к отсутствию Ctrl+E, к сессионному хранилищу и ожиданию завершения сохранения — затем обе прошли. Навигация справки обновлена с прежнего диалога на лист обучения и проверена. Дополнительный просмотр кода не выявил дефектов.

Итог: все три сборки успешны; 16 проверок готовой GitHub Pages сборки прошли одним запуском; 11 проверок данных прошли. Все 48 названий справочника переведены. Снимки просмотрены, отчёт — `docs/qa/2026-10-24-editor-learning.md`. Удалённая публикация не выполнялась.
