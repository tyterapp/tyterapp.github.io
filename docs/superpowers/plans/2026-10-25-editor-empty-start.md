# Начало ввода и инструменты полноэкранного режима

Цель: первое открытие и новый документ сразу показывают курсор, ИНТ/ЭКС и подсказки; приветствие находится только на странице обучения. Полное удаление текста возвращает первую строку к ИНТ/ЭКС. Стрелки в справке используют OpenArrow; ввод `<-` преобразуется в левую стрелку. Машинка опускается ещё на 2px, свет смещается ещё на 2px вправо; отправка телеграммы скрывается только в полноэкранном редакторе.

Используются существующие React DOM, Tiptap/ProseMirror, OpenArrow и CSS. Новый UI или зависимости не нужны. Удаление приветствия включает отказ от автоматического блокирующего тура при первой сессии; страница обучения остаётся доступна вручную. Начальный курсор предусмотрен также для пустого мобильного документа; существующие непустые документы и заметки сохраняют текущие правила фокуса.
