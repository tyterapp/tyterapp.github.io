# Удаление копий сценария

| Было                                                                   | Стало                                                                                                                                                                                                     |
| ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| У созданных версий не было удаления                                    | Рядом с созданной копией появляется значок корзины. На наведении и клавиатурном фокусе он красный; на мобильном размер области нажатия не меньше 44 px                                                    |
| Исходный сценарий мог бы оказаться целью удаления                      | Исходный White защищён. Значка нет у ещё не созданных копий; активная версия без сохранённого исходного White также не считается удаляемой копией                                                         |
| Отмена удаления отсутствовала                                          | После клика копия убирается, а сверху показывается уведомление с кнопкой загрузки «Отменить удаление». Окно отмены — 15 секунд, после чего кнопка отключается и уведомление плавно исчезает               |
| Закрытие уведомления не подтверждало действие                          | Крестик с подписью «Подтвердить удаление копии» прекращает возможность отмены сразу                                                                                                                       |
| Поведение открытой удаляемой версии не было определено                 | Редактор переключается на исходный White. При отмене открытая копия возвращается, а изменения, внесённые в White за время ожидания, сохраняются                                                           |
| Отмена могла бы перезаписать весь документ                             | Восстанавливается только снимок удалённой версии, включая её текст, варианты сцен, настройки кадров, аутлайн, комментарии и библиотеки. Текущие изменения других версий остаются на месте                 |
| История удалённой копии могла бы появиться в новой копии того же цвета | После подтверждения или истечения срока удаляется только история этой копии. До отмены история сохраняется. На время окна отмены создание новой версии в удалённом слоте и повторное удаление блокируются |
| Длинное уведомление могло бы выходить за мобильный экран               | На мобильном текст размещается над кнопками отмены и подтверждения                                                                                                                                        |

Отмена действует в текущем открытом сеансе. Завершение сеанса подтверждает удаление. Параллельно созданная копия с тем же идентификатором не перезаписывается при восстановлении.
