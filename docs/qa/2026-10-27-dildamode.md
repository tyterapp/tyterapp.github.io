# Dilda Mode — проверка от 27 октября 2026

Создана отдельная однократная копия редактора по `/dildamode/`. Основной `src/` не менялся: его контрольные суммы сверены с началом задачи. Ресурсы, документы, кошелёк, история и сохранённые файловые дескрипторы копии отделены. Основной магазин не содержит нового товара.

Внутри копии: монеты → магазин → разное → Dilda Mode. Разовая покупка стоит 100 монет. Повторное открытие бесплатно, покупка сохраняется после перезагрузки. Переключение между предметом по приложенному изображению и помидором включено в покупку. Прицел, полёт предмета, отдача, синтетический локальный звук «УУУУ», счётчик попаданий и кляксы работают поверх сценария без изменения его данных. Закрытие и Escape возвращают курсор редактору.

Модель построена из 186 цветных вокселей по PNG пользователя. Помидор — низкополигональная модель. Обе отрисовываются с проверкой глубины в WebGL. Без WebGL доступен статический вариант предметов. Отрисовка останавливается в покое, звук, отложенные попадания и ресурсы 3D освобождаются при выходе. На листе остаётся максимум 300 визуальных следов, общий счётчик продолжает расти.

Свежая независимая проверка обнаружила действие Undo/Redo и Ctrl+Alt+E за модальным игровым режимом. Оба случая воспроизведены падающими тестами, исправлены в копии до фиксации версии и проверены повторно. Дополнительно заблокирован нативный браузерный Undo за модальным окном. Других существенных замечаний проверки не осталось.
