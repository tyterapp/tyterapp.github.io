# Иконки форматов печатной машинки

Все семь приложенных SVG подключены только к индикатору формата в существующей настольной машинке: INT-EXT → scene, Action → action, Charachter → character, Speal → speech, Remark → parenthetical, Cut → transition, Plain-text → plain. Оригиналы без изменений находятся в `public/typewriter/formats/`. Общие иконки форматирования и мобильный интерфейс не менялись.

Размер 18×18, положение и цветовые фильтры лампы сохранены. Контрольные суммы всех семи файлов совпадают с вложениями; файлы также побайтно совпадают во всех трёх сборках.

Проверки:

- 4 сценария на сервере разработки прошли: все форматы и загрузка SVG при двух состояниях лампы; масштаб 100–200%; отключение настольной машинки при мобильной ширине; положение и работа подсказок.
- В готовой GitHub Pages сборке повторены эти четыре сценария и проверка независимости геометрии клавиатуры от масштаба: 5 проверок прошли.
- Просмотрен снимок всех 14 сочетаний формата и лампы: `typewriter-icons-2026-10-23/icons.png`.
- `npm run build`, `npm run site:build`, `npm run site:github` завершились успешно. Существующие предупреждения о смешанных импортах и размере пакетов остаются.

Браузерные сценарии запускались последовательно в headless Edge на синтетическом документе с заблокированными локальными файловыми запросами. Мобильная проверка — эмуляция, физическое устройство не использовалось. Удалённая публикация не выполнялась.
