# Мобильный Tyter: изменения и проверки

Дата: 21 октября 2026. Мобильный интерфейс ограничен существующим диапазоном 320–831 CSS px. Модель документа и геометрия десктопного экспорта сохранены.

## Что изменилось

| Было | Стало |
| --- | --- |
| Компоненты занимали место в шапке | Иконка компонентов находится в меню инструментов в сценарии и раскадровке |
| Выбор страницы через список, цвет зависел от позиции курсора | Закреплены номер и цвет видимой страницы; смена цвета не перемещает курсор |
| Быстрое форматирование показывалось при чтении | Панель появляется после ввода или вставки, скрывается при выходе из редактирования; полноэкранный режим сохраняет скрытую панель |
| Поля экрана оставались за пределами цвета страницы | Заливка и разделители занимают всю ширину, шапка следует цвету видимой страницы |
| Смена версии без обратной связи | Геометрическая иконка мягко подпрыгивает; reduced motion отключает анимацию |
| Каноническая разбивка пересоздавала DOM при наборе | Отображение обновляется по сохранённым границам, полный расчёт выполняется после паузы |

Дополнительно убраны одинаковые обновления состояния на каждый символ и расчёт скрытой раскадровки на мобильном экране сценария. При открытии раскадровка и инспектор получают актуальный текст.

## Проверки

- **23 проверки данных прошли:** модель цветовых версий, перенос границ, отмена и восстановление, сохранение соседних страниц, миграции, история и TYT round trip.
- **35 сценариев интерфейса прошли одним финальным запуском:** mobile-writing, mobile-workspace, focus-theme и page-versions. Проверены ширины 320/390/831 и переход на десктоп; обе темы; RU/EN; FREE/PRO; набор, вставка, автозамена через insertText, имитация composition, отмена, сохранение и перезагрузка; сенсорное форматирование и внешняя клавиатура; компоненты, библиотеки и экспорт; свежесть раскадровки после набора; reduced motion и полноэкранный телеграф.
- Сборки приложения, сайта и GitHub Pages завершились успешно. Существующие предупреждения Vite о смешанных импортах и размере части пакетов не блокируют сборку.
- Повторная проверка готовой GitHub Pages сборки: **23 сценария прошли**, включая свежесть раскадровки после набора, сохранение цветов, внешнюю клавиатуру и обе темы.

Независимое ревью выявило три ошибки: потерю запланированного полного пересчёта при обновлении метаданных, лишние элементы управления страницей в режиме реплик и потерю фокуса после выбора цвета с клавиатуры. Все три воспроизведены падающими тестами, исправлены и повторно проверены. Повторное ревью дополнительных оптимизаций не обнаружило конкретных проблем.

## Замер ввода

Условия: headless Edge/Chromium, 390×844, CPU throttling 4×, 360 абзацев, 33 символа с задержкой 10 мс между нажатиями, включён CDP CPU profiler. Исходная версия собрана из резервной копии исходников отдельно от рабочего приложения. Замеры выполнены последовательно на одном хосте. Это лабораторное сравнение, а не статистика пользователей.

| Метрика | До | После |
| --- | ---: | ---: |
| Весь автоматизированный набор | 5556 мс | 3036 мс |
| p95 до следующей возможности отрисовки, два rAF | 234,2 мс | 176,5 мс |
| p95 обработки транзакции документа | 21,1 мс | 16,8 мс |
| Полные копии документа за замер | 32 | 1 |
| Полные копии во время непрерывного набора | 32 | 0 |
| Длинные задачи за окно замера | 50 | 21 |
| p95 до первого rAF, диагностическая метрика | 72,4 мс | 98,3 мс |

Метрика первого rAF ухудшилась; её нельзя считать завершением отображения: прежний тяжёлый расчёт выполнялся позже в том же кадре. Поэтому добавлен одинаковый для обеих версий замер через два rAF. Он учитывает следующую возможность отрисовки, но не является INP или измерением физического дисплея. Этот показатель снизился на 24,6%; всё ещё остаются длинные задачи обработки документа. Результат одного парного замера не гарантирует такие же числа на телефоне.

Локальные результаты и методика сохранены в `.cache/mobile-input-paired-before.json`, `.cache/mobile-input-paired-after.json`, соответствующих CPU profiles и `.cache/mobile-typing-profile.spec.js`. Тесты и замеры используют только синтетические документы; обращения к `/__tyter_local/` перехвачены до навигации.

## Референсы и границы проверки

Использованы установленные Superpowers и локальный референс Appllama для PWA: сенсорные цели, работа с клавиатурой, доступные меню, темы и ограничение анимации. Mobbin MCP был запрошен для мобильного редактирования документов, но вернул ограничение платного плана. Примеры Mobbin не были получены и не использовались.

Физические Android/Chrome, нативная IME, виброотклик и установленная PWA на устройстве не проверялись. Проверка выполнена в браузерной эмуляции; миграция на React Native или добавление нативных зависимостей не выполнялись. Изменения подготовлены локально, удалённая публикация на GitHub не выполнялась.
