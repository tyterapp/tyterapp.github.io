# Обучение, горячие клавиши и подсветка компонентов

В лист обучения добавлены вкладки «Привет! / Горячие клавиши» рядом с кнопкой возврата. Поддерживаются стрелки, Home/End и переход к содержимому с клавиатуры. На узком экране шапка переносится без горизонтальной прокрутки. Горячие клавиши используют общий список с существующей справкой; все 48 названий групп и действий имеют английский перевод. Для операций со словами показаны корректные варианты Option на Mac.

В приветствии анимация текста оставлена только у заголовка «Как быстрее работать с текстом?». Абзацы появляются сразу; список горячих клавиш не содержит анимированных букв. Сохранена поддержка уменьшения движения.

Из панели выделения и контекстных меню удалено создание Props. Обработчик Ctrl+E удалён; Ctrl+D, Ctrl+Q и Ctrl+Alt+E сохранены. Существующие записи реквизита и их связь с компонентами не удаляются. Справка больше не предлагает устаревший способ создания реквизита.

Ошибка подсветки воспроизведена до исправления: компонент внутри текстовой ссылки после отключения подсказок наследовал цвет внешнего `a.script-text-link`. В тёмной теме получался `oklch(0.78 0.082 300)` вместо цвета абзаца `rgb(226, 220, 232)`. Исправлен каскад цвета и фона содержащей компонент ссылки. Обычные компоненты и отключённые записи библиотеки проверены в обеих темах; отметки документа сохраняются.

Название экспорта «Instant link · HTML» заменено на «HTML презентация» / «HTML presentation» для сценария и раскадровки.

## Проверки

- До изменения приложения новые вкладки и отсутствие Props ожидаемо не проходили; отдельная проверка вложенной ссылки воспроизвела ошибку цвета. После исправления все шесть новых сценариев прошли.
- В расширенном прогоне на сервере разработки прошли 24 из 26 проверок. Две старые проверки реквизита адаптированы к удалению Ctrl+E, сессионному хранилищу и ожиданию завершения сохранения — затем обе прошли. Отдельно прошла обновлённая проверка навигации справки.
- На готовой GitHub Pages сборке **16 сценариев прошли одним запуском**: русская/английская версия, настольная/мобильная ширина, вкладки и клавиатура, ограничение анимации и reduced motion, цвета, Ctrl+D/Ctrl+Q/Ctrl+Alt+E, перезагрузка настроек, название экспорта на двух языках, автономная HTML-презентация в обоих режимах и её скачивание/отправка.
- **11 проверок моделей данных прошли:** HTML, ссылки компонентов, отчёты количества и экспорт раскадровки. Синтаксис `desktop/main-pro.cjs` проверен; нативное приложение не запускалось.
- Сборки приложения, сайта и GitHub Pages прошли. Существующие предупреждения о смешанных импортах и крупных пакетах не блокируют сборку.
- Дополнительный просмотр изменённого кода не выявил дефектов. Устаревшие ожидания Ctrl+E и названия HTML в прежних тестах обновлены.
- Просмотрены снимки `editor-learning-2026-10-24/shortcuts-desktop.png` и `editor-learning-2026-10-24/shortcuts-mobile-dark.png`: шапка, переносы и контраст клавиш соответствуют текущей теме.

Проверки выполнены в headless Edge на синтетических документах. Локальные файловые запросы перехватываются до навигации. Мобильный вид проверен в эмуляции, физическое устройство не использовалось. Удалённая публикация не выполнялась. Архив исходников: `publication/tyter-github-pages-source.zip`.
