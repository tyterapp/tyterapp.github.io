# Печатная машинка в полноэкранном режиме

23 октября 2026. Изменения ограничены экраном сценария на ПК, полноэкранным режимом и тёмной темой. Мобильная версия сохраняет существующее поведение.

## Что изменилось и зачем

| Было | Стало |
| --- | --- |
| Кнопка машинки без действия | Кнопка в тёмном полноэкранном режиме включает конструкцию из предоставленных SVG |
| Обычные интервалы между форматами | В режиме машинки между абзацами всех форматов 4px; выравнивание и межстрочный интервал внутри абзаца сохранены |
| Не было локального освещения | Лампа плавно включается и выключается за 1000ms ease-in-out, с коротким звуком переключателя |
| Формат и статус не отображались на машинке | Иконка текущего формата, синяя лампа для компонента/ссылки, красная для возможной ошибки в текущем слове |
| Конструкцию нельзя было перемещать | Вертикальное движение переносит направляющую, горизонтальное — каретку bg. Текстовый курсор следует к ближайшей существующей позиции; пустой текст не вставляется |
| Не было поведения машинки при масштабе 200% | Только Tube удваивается по ширине: 936→1872px. Высота Tube 10px, корпус 64×32px и остальные детали сохраняют физический размер |
| Не было выхода из специального представления | Выход из полноэкранного режима, смена темы/документа/режима или переход к мобильной ширине сбрасывают конструкцию и лампу |

Компактное представление использует каноническую разбивку на страницы в невидимой копии обычного сценария. Текст, цветовые версии, история и геометрия PDF/DOCX/FDX от положения машинки и лампы не зависят. Печать скрывает конструкцию и возвращает обычные интервалы. Настройка звука набора текста сохранена отдельно.

Проверка орфографии выполняется локальным словарём, с задержкой 200ms после смены слова и без вычисления вариантов исправления. Недоступный словарь и устаревший ответ не включают ошибку. Предположение об ошибке не является гарантией: имена и термины могут отсутствовать в словаре.

## Проверки

- **33 проверки моделей прошли:** 4 проверки курсора/слов/разрывов строк/ссылок/ограничения координат и 29 проверок цветовых страниц, отмены, истории, TYT, PDF, DOCX и FDX.
- **48 сценариев интерфейса прошли одним запуском:** 11 нового режима, 3 полноэкранного переключения темы, 24 мобильных сценария, 8 цветовых страниц и 2 масштаба/экспорта. Проверены 100→200%, все 7 форматов, оба источника синего индикатора, ошибки/недоступность словаря, звук по жесту, длительность анимации, обе оси перетаскивания и реальное изменение выделения, сохранность текста, режим печати, reduced motion, длинный документ и границы страниц.
- Ревью выявило один дефект: тихое восстановление текста с прежней числовой позицией курсора не обновляло красную лампу. Ошибка воспроизведена отдельным падающим тестом; после подписки на транзакции вместо только update/selectionUpdate тест проходит.
- Устаревший тест масштаба ожидал прежний мобильный лист 580px и адаптивную перепагинацию. Он приведён к ранее реализованному мобильному поведению: лист на всю ширину 390px, канонические границы страниц и закреплённый выбор цвета. Код мобильного интерфейса не менялся.
- 23 исходных изображения/SVG сверены с предоставленными файлами; внешних изображений и активного содержимого в SVG нет. Скриншоты выключенной/включённой лампы и масштаба 200% просмотрены.

- После финального выравнивания затемнения холста с референсом повторно прошли **14 проверок машинки и полноэкранной темы**. Затемнение применяется ко всему холсту и листу, только пока включена лампа.
- Сборки `build`, `site:build`, `site:github` завершились успешно. Основной пакет готового сайта: `index-CaQqJPAt.js`. Существующие предупреждения о смешанных импортах и размере части пакетов не блокируют сборку. Все 23 файла машинки сверены в каждой из трёх сборок.

- **37 сценариев готовой GitHub Pages сборки прошли:** весь новый режим, полноэкранные кнопки, мобильная геометрия/форматирование/компоненты/сохранение/навигация/поиск, reduced motion и переходы между ширинами. Один тест локальной файловой сессии, использующий API исходных модулей, выполнен в прогоне разработки и не запускался против готовой сборки.

Для повторного прогона готового сайта вспомогательное чтение сохранённого документа в двух мобильных тестах перенесено с импорта исходного модуля на чтение того же снимка в IndexedDB. Исходники `/src` намеренно отсутствуют в production. Проверки сохранения и перезагрузки остаются прежними; код приложения не менялся.

Повторный прогон этих двух проверок на сервере разработки тоже прошёл. Скриншоты находятся в `docs/qa/typewriter-2026-10-23/`: выключенная лампа, включённая лампа, перетаскивание и масштаб 200%.

Для передачи исходников используется `publication/tyter-github-pages-source.zip`; локальные копии находятся в `publication/tyterapp.github.io` и `publication/tyter-github-pages-source`. Удалённая публикация и Git checkout в `publication/github-pages-repo` не затрагивались.

Архив содержит 599 файлов. Обе локальные копии сверены с каждым файлом архива; приватные файлы исключены.

Все проверки используют синтетические документы, а `/__tyter_local/` перехватывается до открытия страницы. Проверка выполняется в headless Edge; мобильные сценарии используют эмуляцию ширины/касаний/клавиатуры, физическое устройство и установленная PWA не проверялись. Для звука проверены вызов WebAudio и сохранность курсора; субъективная слышимость физически не оценивалась. Удалённая публикация не выполняется.
