# Сочетания переключения режимов

Сценарий теперь открывается через Ctrl+Alt+1, раскадровка — через Ctrl+Alt+2. Старые Alt+1/Alt+2 больше не переключают режим. Обновлены обработчик, aria-keyshortcuts кнопок, общий справочник клавиш и тексты обучения на русском и английском. В тестах вставки в раскадровку заменены прежние сочетания.

До изменения обработчика проверка ожидаемо падала: Alt+2 продолжал скрывать сценарий. После изменения обе проверки прошли на сервере разработки и повторно обе прошли в готовой GitHub Pages сборке. Проверены переключение из редактора и текстового поля раскадровки, сохранение отредактированного текста, отказ от старых сочетаний, ограничение Free, доступные описания клавиш и справка на мобильной ширине.

Все три сборки — приложение, сайт и GitHub Pages — завершились успешно. Проверки выполнялись в headless Edge на синтетических документах с перехватом локальных файловых запросов. Мобильная ширина проверена в эмуляции. Удалённая публикация не выполнялась. Архив исходников: `publication/tyter-github-pages-source.zip`.
