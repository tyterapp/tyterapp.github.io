# Обновление редактора: мобильная версия, заметки и награды

Изменения собраны локально. Публикация сайта и сетевой мультиплеер в это обновление не входят.

| Было | Стало |
| --- | --- |
| Настольная раскладка на узком экране | Мобильная раскладка только при ширине 320–831 px; с 832 px сохраняется настольная |
| Широкий лист и элементы вокруг текста | Непрерывный лист по ширине телефона, кнопки сцены над заголовком, удобные области нажатия |
| Клавиатура могла закрывать инструменты | Нижнее форматирование следует за видимой областью над клавиатурой и сохраняет курсор; при открытии страницы клавиатура не вызывается |
| Компоненты и боковые панели занимали место рядом с листом | Компоненты и инструменты открываются в шторках; библиотеки, комментарии и настройки адаптированы к узкому экрану |
| Разные пути локального сохранения | Полный документ хранится в общем локальном складе браузера; экспорт сохраняет актуальный снимок всех версий. Идентификаторы сессии и вкладки передаются через адаптер будущего сетевого хранения |
| Подключение папки могло пересечься с автосохранением | Сохранение текущей вкладки завершается до смены папки; загрузка локальных файлов завершается до открытия панелей |
| Синтезированный звук печати | 48 MP3 из предоставленного архива, постоянное назначение физическим клавишам в обеих раскладках; поддержка экранной клавиатуры и однократное воспроизведение каждого ввода |
| Звук создавался заново при вводе | MP3 декодируются один раз после первого нажатия; одновременно воспроизводится не больше восьми звуков |
| Мухи только внутри значка, предел 24 | Одна муха на ошибку, не больше 12 суммарно в значке и поверх интерфейса; маленькие SVG медленно перелетают и садятся на края компонентов |
| Декоративные эффекты продолжали работать | Полёты приостанавливаются в скрытой вкладке; настройка уменьшения движения отключает анимацию; мухи не перехватывают нажатия |
| У обычного уведомления был только крестик | Добавлена кнопка «Перейти» без перехода. Уведомление автоматически исчезает после пяти секунд; ссылка «Подробнее» в предупреждении о Courier остаётся действующей |
| Не было ежедневной награды | Один первый вход в календарный день даёт одну монету. Каждый пятый непрерывный день добавляет десять; за пять дней всего 15 монет. Повторные входы и вкладки не дублируют награду |
| В списке версий был только выбор сценария | Рядом с названием каждой версии есть кнопка её заметок |
| Не было отдельного редактора заметок | Изолированные заметки каждой версии, Inter 18 px/1.6, обычный текст без оформления и сценарных форматов; оформленная вставка также становится обычным текстом |
| Инструменты работали только со сценарием | В заметках доступны поиск, комментарии с цветами и статусами, компоненты, реквизит, отмена и история; восстановление заметок не заменяет сценарий и аутлайн |
| TYT сохранял сценарий и его версии | TYT также сохраняет заметки всех версий. PDF, Word и FDX экспортируют сценарий; увеличенный постер, номера и варианты сцен проверены для PDF и Word |

## Цвета и состояния

Новые элементы используют существующие цвета интерфейса. Коричневое заполнение значка доктора по количеству ошибок сохраняется.

| Было | Стало |
| --- | --- |
| Начальный цвет доктора зависел от `--ui-muted` | Светлая тема: `oklch(0.514 0.021 295)`; тёмная: `oklch(0.72 0.021 295)`; затем плавная примесь существующего коричневого |
| Светлые мухи внутри значка | Тело всех мух: `oklch(0.39 0.006 285)`, прозрачность 50%; крылья: `oklch(0.55 0.008 285 / 0.65)` |
| Отдельная прямоугольная подложка внутри тёмного поиска | Общая подложка `--ui-soft` (`#36313e`), рамка `--ui-border` (`#38343f`); вложенный инпут прозрачный |
| Неодинаковые фоны и цвета текста тёмных полей | Фон обычных полей: `oklch(0.26 0.015 285)`; текст `--ui-text` (`#e2dce8`), рамка `--ui-border` (`#38343f`) |
| Бледная горячая клавиша в подсказке | Фон `--ui-soft` (`#36313e`), текст `--ui-text` (`#e2dce8`), рамка `--ui-border` (`#38343f`) |
| У обычного уведомления не было кнопки действия | «Перейти»: чёрный текст `oklch(0 0 0)`, фон `oklch(0.972 0.008 300)`; при наведении `oklch(0.916 0.021 300)`, фокус `oklch(0.49 0.054 300)`; без системной тени и рамки |
| Нет кнопки заметок | В обычном состоянии `--ui-muted`; при наведении фон `--ui-soft` и текст `--ui-text`; обводка фокуса `--ui-accent` |
| Нет панели инструментов заметок | Мягкая тень `oklch(0 0 0 / 0.08)`; панели и мобильные шторки используют существующие цвета поверхностей, текста и рамок |
| Нет мобильных шторок и поднятой панели форматирования | Затемнение фона шторки `oklch(0.18 0.025 285 / 0.32)`, её тень `oklch(0 0 0 / 0.14)`; тень панели форматирования `oklch(0 0 0 / 0.035)` |

## Проверка

Проверены ширины 320, 390, 831 и 832 px, поведение при изменении видимой области клавиатуры, шторки и библиотеки, сохранение полного документа, заметки и их история, реальные декодированные MP3, награды между вкладками, предел мух и уменьшение движения, тёмные поля и подсказки. Проверены также редактирование, комментарии к вариантам сцен, поиск, копирование оформления, таймер, задания, экспорт PDF и Word и автосохранение TYT в локальную папку.

Мобильные проверки выполнены в браузере с изменяемой шириной и моделированием видимой области клавиатуры. Синхронизация между телефонами и совместное редактирование пока не реализованы: склад общий для вкладок этого браузера на этом устройстве.
