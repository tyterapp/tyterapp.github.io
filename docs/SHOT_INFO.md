# Информация о кадре

| Было                                              | Стало                                                                                                                                                                                                                               |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| У сцены не было настроек кадра                    | Кнопка Crop справа открывает сайдбар; на мобильном экране — шторку. Геометрия SVG взята из приложенного Crop.svg, цвет наследуется от интерфейса                                                                                    |
| Кнопки информации не было                         | Высота, радиус и фон соответствуют переключателю A–F. Незаполненная кнопка имеет непрозрачность 20%, при наведении и фокусе — 100%; заполненная — всегда 100%. Область нажатия 40 px, на мобильном — 44 px                          |
| Не было примера шота                              | Три публичных примера с главной страницы ShotDeck включены в сборку; можно прикрепить своё JPG, PNG или WebP до 5 МБ. Изображение уменьшается до 640 px; SVG не принимается                                                         |
| Не было параметров съёмки                         | Название шота, соотношение сторон, оптический формат, крупность, формат съёмки, тип кадра, время суток, люди, композиция, объектив, характер и источник света, требования по наготе/насилию. Для каждого поля есть текстовый пример |
| Не было автоматического хронометража              | Доля страницы форматированного текста Courier умножается на 60 секунд. Учитываются ширина абзацев, переносы и межабзацные отступы полной страницы экспорта; масштаб и ширина экрана на оценку не влияют                             |
| Не было автоматического времени суток             | Оно определяется по окончанию заголовка. Пользователь может задать другое значение; возврат к автоматическому режиму снова отслеживает заголовок                                                                                    |
| Настроек кадра не было в файле                    | `sceneShots[sceneId][A–F]` сохраняется в локальном файле, TYT и истории. Версии White–Cherry имеют изолированные снимки этого поля. Небезопасные изображения и неизвестные значения отклоняются при импорте                         |
| Список блоков сцены отсутствовал                  | Заголовок, действие, персонаж, диалог, ремарка, переход и заметки показаны в порядке текста. Нажатие возвращает к нужному абзацу; на мобильном шторка закрывается                                                                   |
| Отчёта не было                                    | PDF содержит выбранную версию сценария, все сцены и сохранённые варианты A–F, параметры, оценку времени, примеры кадров, полный список блоков, ссылки на ShotDeck и номера страниц                                                  |
| Подсказки времени ограничивались четырьмя словами | Добавлены СУМЕРКИ, РАССВЕТ, ВОСХОД, ЗАКАТ, ПОЛДЕНЬ, ПОЛНОЧЬ, ПОЗЖЕ и ПРОДОЛЖЕНИЕ с английскими эквивалентами. Доктор использует тот же список. Длинные подсказки прокручиваются и учитывают экранную клавиатуру                     |

Хронометраж — оценка по объёму сценария, а не точная длительность монтажа. Флажки исключения наготы и насилия сохраняют требования к кадру, но не анализируют загруженные пользователем изображения.

Ссылки на первоисточник сохраняются отдельно от локальных копий, чтобы отчёт оставался атрибутированным. Прикреплённые изображения подписываются как изображения пользователя.
