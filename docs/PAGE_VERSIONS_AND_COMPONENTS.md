# Версии страниц и связи компонентов

Выбор цветовой версии находится у каждой страницы сценария. Переключение заменяет только текст этой страницы. Если текст переполняет страницу, продолжение переходит в выбранную версию следующей существующей страницы. Её номер и версия сохраняются. Новые страницы наследуют выбранную версию предыдущей страницы и получают собственный идентификатор и пустой набор альтернатив: сохранённые копии соседних страниц на них не размножаются. Перенос меняет только границы живого текста, без потери символов, форматирования и закладок; неактивные версии остаются на своих страницах. Короткая версия, выбранная пользователем, сохраняет отдельный лист до тех пор, пока перенос из предыдущей страницы её не достигнет. Автоматический перенос и исходное редактирование отменяются одним Ctrl+Z. Признак автоматического продолжения `flow` сохраняется в TYT и истории; старые файлы без него остаются совместимыми.

Цвет версии применяется только к самому листу; фон вокруг документа остаётся нейтральным при переходе курсора между страницами. На телефоне выбор страницы и версии находится над текстом. Структура проекта, библиотеки компонентов и аутлайн общие для документа.

Поиск по умолчанию использует выбранные версии всех текущих страниц документа. «Искать во всех версиях» добавляет сохранённые альтернативы только этих страниц. Снимки истории и версии удалённых страниц в поиск не входят; данные для восстановления сохраняются отдельно. Карточка показывает номер страницы, цвет и геометрическую фигуру версии. Переход выбирает нужную альтернативу только у найденной страницы и прокручивает текст к курсору.

PDF, DOCX и FDX собираются из выбранных версий страниц. Название версии находится слева на уровне номера страницы. PDF окрашивает страницу в цвет версии. FDX передаёт цвет, название и границы через стандартные поля ревизий; окончательное отображение зависит от редактора Final Draft. TYT сохраняет весь проект, включая альтернативы и историю. Старые версии всего документа мигрируют с отдельным измерением каждой ветки, а исходные снимки сохраняются в архиве модели.

Удаление копии относится к одной странице; White удалить нельзя. Удаление можно отменить в течение 15 секунд. Общая история документа сохраняется, поскольку один снимок может содержать версии нескольких страниц.

Зажигалка сжигает только выбранную версию последней страницы, включая White. Если у этой страницы есть другие сохранённые версии, открывается White либо первая доступная версия по порядку. Остальные версии этой и соседних страниц сохраняются. Без альтернатив последняя страница удаляется, а единственная страница сбрасывается в пустую White со строками INT/EXT и действия. Ctrl+Z и повтор восстанавливают текст вместе с выбранной версией и её альтернативами; сожжённая версия не участвует в поиске до отмены сжигания. Перед сжиганием записывается общий снимок истории.

Строка компонента или реквизита открывает отдельную панель свойств. «Назад» возвращает фильтр и позицию списка. Переход к компоненту, занявшему алиас, не сохраняет ошибочный ввод: черновик остаётся доступен при возврате. «Отмена» сбрасывает черновик, «Сохранить» записывает валидные значения.

В свойствах персонажа доступны направленные и двусторонние связи: тип, название, состояние, описание и необязательная сцена. Можно перейти к связанному персонажу, изменить или удалить связь и отменить последнее действие. Смена категории скрывает связи без удаления. Недоступный участник отображается как недоступный и может быть заменён. Связи, исходные идентификаторы библиотек и скрытые данные сохраняются в TYT, TYTL и истории; обновление старой библиотеки без этих полей их не очищает.

В подсказках у выбранной строки показано Ctrl + Enter. Ширина блока — 248 px с ограничением по ширине экрана. Панель быстрого форматирования использует иконку человека для реплики и звука для ремарки.

Переключатель версии на компьютере расположен слева сверху внутри каждого листа, на уровне номера страницы: префикс версии, цветная фигура, название и шеврон. В покое у переключателя нет заливки или рамки. На телефоне сохраняется отдельная полоса выбора страницы и версии с областями нажатия не меньше 44 px.

Проверка модели, файлов и экспорта: `npm run test:models`. Проверки браузера запускаются отдельно через `npm test`; прежние проверки версии всего документа, которые больше не соответствуют интерфейсу, сохранены в `tests/legacy`.
