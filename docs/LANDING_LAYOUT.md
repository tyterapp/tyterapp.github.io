Новые прямые маршруты определены в `src/site-content.js` и создаются обеими сборками сайта. Готовая GitHub Pages сборка содержит собственный `index.html` для `/b`, `/blog`, `/help` и каждой статьи, поэтому прямой вход и перезагрузка возвращают HTTP 200. Неизвестные адреса продолжают возвращать 404.

Ссылки навигации: логотип и «Продукт» — `/`, «Блог» — `/blog`, «Помощь» — `/help`, чат — `https://t.me/ultraproduct`, пробная версия — `/free`. Лендинг меняет только оформление и переходы; оплату он не обрабатывает.

Превью функций построены средствами интерфейса, исходное видео служит только референсом и не включено в публикацию. Статья о сценарном формате ссылается на первоисточник Final Draft; статьи о сохранении и аутлайне описывают существующее поведение Tyter.
