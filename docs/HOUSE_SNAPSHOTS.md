# Снимки домика

Камера рядом с расширением панели делает PNG всего домика в исходном разрешении 734 × 468. Масштаб 100/200%, прокрутка, тема интерфейса и кнопки управления в снимок не входят. Снимок и ссылка доступны до закрытия панели; скачанный файл и уже скопированная ссылка остаются пригодными к использованию.

Публичный просмотр доступен без покупки и без входа в редактор. Новые ссылки используют `/house/v1/empty/` для пустой комнаты и `/house/v1/oiia/0/` … `/house/v1/oiia/3/` для кадров скина. Точный момент снимка сохраняется в `#snapshot=…`. Он не запускает редактор, кошелёк или проверку PRO. Ссылка содержит только версию комнаты, момент снимка и при наличии питомца — ID скина и номер зафиксированного кадра, без текста сценария, монет, персональных данных или доступа к изменению домика. На GitHub Pages не нужен сервер хранения изображений.

Для каждого визуального состояния сборки `site:build` и `site:github` создают отдельную HTML-страницу и `cover.png` 1200 × 630 px. В исходном HTML находятся Open Graph и Twitter Card: абсолютный HTTPS-адрес картинки, её тип, размеры, описание, заголовок и канонический адрес сцены. Сервису превью не нужно выполнять JavaScript, входить в редактор или читать фрагмент URL. В картинке сохраняется весь домик с нужным кадром питомца, без обрезки. Кадры имеют разные адреса страниц и обложек, чтобы их превью не смешивались. При копировании снимка эти страницы уже опубликованы вместе с редактором, поэтому загрузка изображения на сервер не требуется. Метаданные следуют [Open Graph](https://ogp.me/).

Старые `/house#snapshot=…` продолжают открываться; у общей страницы `/house` есть обложка пустого домика. Если соцсеть убрала фрагмент новой ссылки, публичный просмотр восстанавливает сцену из пути. Несовпадение пути и дескриптора, неизвестный скин, кадр или версия не принимаются.

Фон комнаты использует неизменяемый публичный файл `/oiia/house-snapshot-v1.png`. Камера формирует PNG через canvas и накладывает текущий кадр выбранного скина с теми же пропорциями и отступами, что в домике. Публичный просмотр собирает точно такой же PNG; короткий дескриптор полностью воспроизводит сцену. Допустимы только скины из каталога и целочисленные номера их кадров. Старые ссылки без скина сохраняют пустую комнату. Фон и опубликованные кадры нельзя менять по прежним URL: новая графика требует новых адресов, иначе изменятся уже отправленные снимки.

Копирование использует буфер обмена. При отказе браузера поле со ссылкой фокусируется и выделяется для ручного копирования. Системная отправка показана только при наличии `navigator.share`; отмена не закрывает снимок. Создание и скачивание доступны офлайн при уже загруженном домике. Blob URL освобождается после нового снимка и закрытия панели.
