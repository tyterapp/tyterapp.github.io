# Снимки домика

Камера рядом с расширением панели делает PNG всего домика в исходном разрешении 734 × 468. Масштаб 100/200%, прокрутка, тема интерфейса и кнопки управления в снимок не входят. Снимок и ссылка доступны до закрытия панели; скачанный файл и уже скопированная ссылка остаются пригодными к использованию.

Публичный просмотр `/house#snapshot=…` доступен без покупки и без входа в редактор. Он не запускает редактор, кошелёк или проверку PRO. Ссылка содержит только версию комнаты и момент снимка, без текста сценария, монет, персональных данных или доступа к изменению домика. На GitHub Pages не нужен сервер хранения изображений.

Сейчас вся сцена домика состоит из одной неподвижной картинки. Для неё используется неизменяемый публичный файл `/oiia/house-snapshot-v1.png`, общий для отображения домика и публичного снимка. Камера отдельно формирует скачиваемый PNG через canvas. Поэтому короткий дескриптор полностью воспроизводит нынешнюю сцену. При добавлении питомцев, декора и пользовательских изображений необходимо расширить дескриптор снимка и публичный рендерер; нельзя просто менять текущий файл v1 — это изменит ранее отправленные снимки.

Копирование использует буфер обмена. При отказе браузера поле со ссылкой фокусируется и выделяется для ручного копирования. Системная отправка показана только при наличии `navigator.share`; отмена не закрывает снимок. Создание и скачивание доступны офлайн при уже загруженном домике. Blob URL освобождается после нового снимка и закрытия панели.
