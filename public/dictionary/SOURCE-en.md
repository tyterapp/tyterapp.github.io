# English spelling dictionary

The English Hunspell dictionary (`en.aff`, `en.dic`) is distributed by
[wooorm/dictionaries](https://github.com/wooorm/dictionaries/tree/main/dictionaries/en),
based on SCOWL. Downloaded on 2026-10-07.

The original copyright notices and MIT/BSD terms are preserved in `LICENSE-en`.
Tyter checks words locally in a worker using [nspell](https://github.com/wooorm/nspell).
No screenplay text is sent to an external spelling service.
